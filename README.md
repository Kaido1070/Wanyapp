# Rany — iPhone

تطبيق iOS أصلي باستخدام SwiftUI، مرتبط بـ **https://wany.site** ونفس الحسابات والشارات. هوية Rany الجديدة تستخدم خط Script مضمّنًا وشعار R من الخط نفسه؛ معرّف الحزمة ومسارات الحسابات القديمة محفوظة لضمان الترقية.

**تحميل التطبيق (آخر إصدار):** https://github.com/Kaido1070/Wanyapp/releases/latest

## المزايا

- تنزيل قصة كاملة (يجمع جميع صفحات قائمة الفصول أولًا)، فصل واحد أو مجموعة مختارة.
- عدد الفصول المكتملة والمتبقية، البايتات المحملة، السرعة، والحجم الإجمالي عندما تتوفر أحجام الصور. لا يظهر إجمالي وهمي: خدمة الصور الحالية لا تدعم HEAD؛ يظل الإجمالي قيد الحساب حتى تُعرف الأحجام من استجابات GET.
- قائمة تنزيل دائمة، إيقاف واستكمال، إعادة محاولة الناقص فقط، التحقق من الصور قبل اعتبارها مكتملة، وخيار Wi-Fi فقط.
- ملفات صور وبيانات القصص في Application Support وليست ذاكرة متصفح أو URLCache قابلة للمسح تلقائيًا.
- قراءة أوفلاين وحفظ موضع الصفحة والتقدم محليًا، ثم مزامنة التحديثات المعلقة عند الاتصال وفتح التطبيق. الحسابات معزولة والتوثيق محفوظ في Keychain.
- الاستكشاف، الجديد، FYP، الملف الشخصي، المفضلة، حالات المكتبة، إحصائيات السيرفر، القوائم، الأصدقاء والنشاط.
- خوارزميات FYP والجديد ودمج المصادر مأخوذة من كود العميل في anytime عند commit `6126fba2ce6e089def0f37725f554f7a23cef865`. تُشغّل حساباتها محليًا بواسطة JavaScriptCore مع شبكة URLSession؛ لا WebView ولا صفحة ويب ضمن التطبيق.
- تنقل أصلي: TabView من النظام ولكل تبويب NavigationStack مستقل يحفظ مكانه، وانتقالات النظام وسحب الرجوع من الحافة في كل الشاشات. الضغط على التبويب الحالي يرجع لأول صفحة ثم يصعد لأعلاها.
- عناوين كبيرة أصلية تصغر مع التمرير، وشعار R وزر الإعدادات في شريط النظام.
- إخفاء الشريط السفلي عند النزول وإظهاره عند الصعود (على iOS 17 و18 و26).
- Liquid Glass على iOS 26 (يُبنى بـXcode 26 على macos-26): أشرطة النظام تلقائيًا، والبطاقات والعناصر العائمة بـglassEffect، ومواد النظام على iOS 17 و18. خيار الزجاج وقوته في الإعدادات يتحكم بها، وتقليل الشفافية يستبدلها بأسطح صلبة.
- أداء: أغلفة مصغرة تُفك في الخلفية مع NSCache، وخلفية متحركة تتوقف أثناء التمرير والتنقل والقراءة، وObservation بدل ObservableObject، ومحرك الخوارزميات وفك JSON والملفات خارج الخيط الرئيسي، وقوائم كسولة بمعرفات ثابتة.

## بناء IPA

من تبويب Actions شغّل **Build Rany IPA**، ثم نزّل artifact **Rany-IPA-unsigned** وفك ZIP. الملف داخله `Rany-<version>.ipa` غير موقّع ويحتاج توقيعًا عبر أداة التثبيت الخاصة بك؛ لا يحتوي المشروع شهادات أو مفاتيح Apple.

محليًا على macOS مع Xcode:

```bash
brew install xcodegen
xcodegen generate
xcodebuild build -project Wany.xcodeproj -scheme Wany -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath build CODE_SIGNING_ALLOWED=NO
mkdir -p output/Payload
cp -R build/Build/Products/Release-iphoneos/Wany.app output/Payload/
(cd output && zip -qr Wany.ipa Payload)
```

الحد الأدنى iOS 17. يلزم Xcode 26 (macOS 26) لبناء التطبيق بزجاج iOS 26؛ البناء بإصدار أقدم من Xcode يعمل لكن بدون Liquid Glass. يحدث البناء عند تغيير ملفات التطبيق فقط أو تشغيله يدويًا؛ لا توجد جداول تشغيل دورية.

## التحقق

```bash
node --test scripts/feed-engine.test.mjs
xcodebuild test -project Wany.xcodeproj -scheme Wany -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

راجع `QA.md` لاختبار القبول على الجهاز. نجاح البناء لا يغني عن اختبار تسجيل الدخول والتحميل من المصادر الحية بحساب حقيقي.

## تفاصيل وحدود مهمة

- تنزيل الصور المجدولة يستخدم background URLSession. تجهيز قوائم الفصول الجديدة يحتاج بقاء التطبيق نشطًا؛ عند العودة يكمل من الحالة المحفوظة. iOS قد يؤجل عمليات الخلفية، والإغلاق بالقوة يوقفها إلى إعادة الفتح.
- انقطاع صورة لا يمس الصور المكتملة. إذا لم يدعم المصدر استكمال بايتات الصورة الجزئية، تبدأ تلك الصورة وحدها من جديد.
- تقدم القراءة يعمل أوفلاين. تغييرات المفضلة والقوائم والحساب تحتاج إنترنت.
- مزامنة القراءة تعتمد على واجهة progress الحالية للموقع. حماية آخر فصل من التحديثات القديمة أضيفت إلى anytime في commit `c68e01e8c71501019065d7acca7c9fd160d6a5e7`، مع خمسة اختبارات SQLite ناجحة محليًا.
- لا تدعي هذه النسخة مطابقة كل محررات إعدادات الموقع والإدارة؛ لا تشمل لوحة الإدارة أو تعديل ترتيب أقسام البروفايل وسحب عناصر القوائم وإدارة كلمة المرور من داخل التطبيق بعد.
- الشهادات وحساب Apple وأي بيانات اعتماد للمستخدم لا توضع في المستودع.

لتحديث خوارزميات الموقع لاحقًا: وفر checkout موثوقًا لـ anytime ثم شغّل `node scripts/build-feed-engine.mjs /path/to/anytime` وراجع الفرق واختبارات `feed-engine.test.mjs`.
